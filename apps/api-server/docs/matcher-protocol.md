# API 与季度匹配器的边界

HTTP／JSONL 的类型、端点、错误和资源限制统一维护在[匹配器 v1 协议](../../../libs/anime-matcher/PROTOCOL.md)。API 使用 HTTP 传输，由服务管理器维护 worker 进程和模型资源。

数据库保存权威目录、待生效快照、静默窗口及队列；worker 只持有派生缓存。API 用规范化内容的 SHA-256 标识目录，上传成功后才激活新版本，缓存丢失时显式恢复。完整目录用于全局索引，单次候选由业务计算，空候选表示正常拒答。

传输超时可能发生在远端已激活目录之后，因此恢复先查询实际版本，再决定是否重传。API 校验响应的请求 ID、目录版本和结果候选范围，组件故障交给队列保留并处理。目录与结果提交的设计见[匹配流程](torrent-matching.md)。
