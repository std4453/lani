# 媒体池与剧集版本

媒体池保留原件，剧集版本描述一组视频和字幕，剧集的当前版本表示已写入媒体库的文件。Jellyfin 识别状态继续由 `jellyfinEpisodeId` 表示：文件切换成功即更新当前版本，刷新失败只重试识别，不重复导入或替换。

## 存储与归属

媒体池使用 SHA-256 内容寻址，路径为 `root/sha256/前两位/hash`，入池前后校验内容和文件身份。原件不随版本替换或取消发布删除；本期不做垃圾回收。下载路径和 Jellyfin 路径各最多一个，路径、关系类型和文件身份一并保存。外部硬链接数是这两个位置中 `mode=hardlink` 的数量；复制不计入。这个数量仅表示登记关系，不包括外部工具自行建立的链接。

下载与手工导入共用入池、版本登记、版本发布流程。每个版本含一个视频及同 stem 的附属字幕，不自动沿用旧版本字幕。当前目录有未登记字幕时拒绝切换，由维护者先确认归属。版本的操作标识固定到任务及批量条目，重试不递增版本。任务表没有新增媒体外键，历史任务保留；已进入文件阶段却缺少版本关联的旧任务明确失败，需要重新创建。

配置 `mediaPool.root` 是 API 可见的绝对路径。根目录、下载目录和播放器目录应位于同一挂载卷。默认只接受硬链接；只有 `EXDEV` 且显式开启 `painfullyAcceptCrossDeviceCopy` 才复制，并在启动时警告。源文件始终保留，旧 `lani.moveStrategy` 不再控制新媒体导入。符号链接路径和重复外部目标会被拒绝。

## 切换与恢复

所有新文件先在目标目录准备并校验，旧目标建立同目录备份；准备失败时现有媒体不变。准备记录写入 `media_publications` 后才开始替换和撤下旧目标。单文件使用同目录 rename；多个文件无法在文件系统中同时原子切换，日志使部分切换可以恢复。

短数据库事务同时更新资产外部关联、当前版本、清空旧 Jellyfin 识别 ID，并标记切换已提交。事务之前失败则恢复旧文件；提交结果不明时先回读，数据库不可用就保留日志，禁止猜测提交结果。启动时在下载任务恢复前处理全部日志：未提交的回滚，已提交的清理备份。恢复可重复执行；目标被外部修改时停止并保留现场，不覆盖未知文件。

取消等待在途文件操作收敛：提交前回滚，提交后保留当前版本。失败或进行中的任务保留剧集发布占用，需重试或取消后才允许新任务采用其他版本；已成功或已取消任务不永久阻断替换。服务按现有单 API 实例运行，文件操作在实例内串行化；回填需停 API worker，不能与运行实例并发。没有多实例租约。

## 发布准备与历史回填

本次只有一个 schema migration，保留全部历史任务和剧集字段。SQL 不访问文件系统；已有可用剧集通过独立工具回填。部署前先备份数据库，暂停 API worker，在相同媒体卷准备 `pool` 目录和写权限，加入：

```yaml
mediaPool:
  root: /data/pool
  painfullyAcceptCrossDeviceCopy: false
```

迁移后使用新代码生成回填清单，审核视频、字幕关联与路径，再应用。以下命令在构建后的 `apps/api-server` 执行（容器内也可直接运行 `node dist/media-pool/backfill-cli.js`），`CONFIG_FILENAME` 指向本次目标配置；工具仅加载配置、Prisma 和文件服务，不启动 Nest 应用、下载恢复或 cron。

```bash
CONFIG_FILENAME=./config.yaml node ../../common/scripts/install-run-rushx.js media:backfill --scan plan.json
CONFIG_FILENAME=./config.yaml node ../../common/scripts/install-run-rushx.js media:backfill --apply plan.json
```

扫描只读 Jellyfin 和媒体文件，在本地写入新清单；无法唯一识别视频或外部字幕路径时失败，不产生部分清单。清单含本机路径，应保存在忽略目录。应用逐集核验关联和内容哈希，再从现有 Jellyfin 文件入池并登记当前版本；来源标为 `unknown`，不伪造下载任务或下载路径。已有文件保持原位，Jellyfin ID 不变，重复应用幂等。中途失败可以修复原因后重跑；不会删除不在清单中的历史文件。未回填的可用剧集暂时拒绝替换。

验证当前版本、媒体池原件和目标文件身份后，再启动新 API、Data Server 和 Gateway。新内部表通过 Smart Comment 隐藏，当前版本字段禁止原生 GraphQL mutation 修改。本期没有新增前端界面，也不自动执行共享环境回填。
