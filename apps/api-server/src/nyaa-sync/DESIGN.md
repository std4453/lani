# Nyaa 同步设计

RSS、详情和历史列表共用串行请求队列及全局退避，避免不同入口分别限速后仍叠加请求。403/429 会暂停整个客户端。当前限速和手动刷新队列属于单 API 进程，扩展副本时需重新设计共享限流。

自动扫描用分页加载近期待处理和失败记录，避免早期失败阻挡新数据。手动刷新复用同一队列并优先处理；重启会丢失手动刷新意图，自动扫描按持久化状态恢复。刷新成功后才替换元数据，等待或暂时失败保留旧结果。

标题与页面证据分开解析，合并时具体字幕语言优先于笼统声明，简繁证据优先于 zh。纯解析和固定语料见 [`@lani/parse-nyaa`](../../../../libs/parse-nyaa/README.md)。新增规则按页面结构归纳，并用独立标注检查误报、漏报和未知分类。

元数据迁移只修改结构及由 API 接管的函数，历史抓取通过独立流程完成，避免迁移扫描全量种子。先迁移再启动新版 API/Data Server。
