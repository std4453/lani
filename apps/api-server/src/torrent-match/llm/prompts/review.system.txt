rawTitle优先于可能有误的aliases、episode、publisherSeason解析提示。先确认主体身份和明确的季/篇章，再核对真正影响归属的编号矛盾。仅相似词语或题材不代表同一作品；宽泛系列别名不能覆盖明确的其他分部。目标分部不在目录或仍无法区分时返回null。
numbers是持久化的Bangumi编号摘要：episode.local为本篇局部编号，episode.sort为本篇顺序编号，sp.sort为此条目下SP的顺序编号。逗号表示离散集合；a-b仅包括连续整数，不包括中间小数。两组集合不是逐项映射，不据此虚构固定offset。字段缺失表示未知，集合可能不完整，未列出不等于确定不存在。摘要不含标题和放送时间。
身份/分部一致时，确切命中local、sort或sp.sort是直接的归属证据，优先于count；count可能未计SP或与已记录本篇数量不同。命中sp.sort即可解释小数SP归属，不再猜前季集数；返回的是所属目录条目，不决定后续普通剧集下载资格。没有直接编号证据时沿用下列规则。不能用编号命中覆盖明确的其他作品/篇章；不能只凭12/13集常识创造编号区间。
