# 智能下载

智能下载从已匹配到当前季度的种子中，为已发布且媒体库中尚未存在的正篇单集选择资源。它依赖季度匹配、种子解析和剧集放送时间；Nyaa 资源还需完成详情抓取。词法匹配模式的识别准确率较低，不建议开启智能下载。

智能下载与普通标题匹配规则的自动下载互斥，开启后保留已有规则，手动下载仍可使用。设置随季度配置保存生效。

![智能下载设置与种子预览示例](/img/smart-download/settings-light.png)

## 选择资源

资源需要唯一对应本季度的一集正篇。编号同时参考剧集编号和 Bangumi 排序号，存在冲突时跳过；特殊篇、非整数集数、合集以及缺少放送时间的剧集不会自动下载。

下载时间由剧集放送时间加上提前或延后偏移得到，下载窗口约束种子的发布时间。即使两天后才开启智能下载，只要历史资源在对应剧集窗口内发布，仍可被选中。多个剧集同时发布时分别计算窗口。同集的合格资源按发布时间从早到晚选择。

字幕要求中的「中英字幕」接受中文或英文任一种，「任意」允许无字幕。标注 Baha 的资源默认视为有中文字幕。开启 Baha 优先后，同集存在符合其他规则的 Baha 资源时，会取消仍在下载中的其他智能下载任务，下一轮重新选源；已完成下载或手动创建的任务保留。

预览与后台下载使用同一套候选判定规则；预览还会显示不符合规则的资源及其原因，便于保存设置前核对。

## 超时与取消

后台每分钟重新检查候选。下载超时从 qBittorrent 的种子加入时间计时，重启 lani 不重置计时；复用下载器已有种子时沿用原时间。留空或填 0 表示不限制，已完成下载的种子不因超时被取消。

失败、超时取消或用户手动取消的智能下载资源，会从该集之后的自动候选中排除；因 Baha 换源取消的资源仍可再次选择。取消清理失败时，可重试清理，清理完成前不会创建竞争任务。

关闭季度的智能下载只停止后续自动选源，已经创建的任务仍按创建时的参数执行。

## 规则集

在 lani 的 API 配置文件中添加 `smartDownload.rules.title.excludes`，重启服务后生效。任意一条正则匹配到种子标题，该资源就会被排除。

```yaml
smartDownload:
  rules:
    title:
      excludes:
        - '/Some-Raws/i'
        - '\[不需要的发布组\]'
```

支持普通 JavaScript 正则字符串，以及 `/表达式/标志` 写法；`i` 表示忽略大小写。为保证多次判断结果一致，不接受 `g`、`y` 标志。非法正则会使配置校验失败，请先修正再启动。

误匹配可通过规则集暂时避开，并在 [GitHub Issues](https://github.com/std4453/lani/issues) 提供资源标题及预期季度、集数。
