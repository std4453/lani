# 智能下载

智能下载从已匹配到当前季度的种子中，为已发布且媒体库中尚未存在的正篇单集选择资源。它依赖季度匹配、种子解析和剧集放送时间；Nyaa 资源还需完成详情抓取。

在季度详情的「下载配置」中点击「开启智能下载」，阅读提示后配置字幕、下载窗口和超时。弹窗中的「确定」将修改写入页面草稿，最后还需保存季度配置。弹窗「取消」丢弃本次修改；开启或关闭智能下载会保留原有的标题匹配规则和智能下载设置。

![智能下载设置与种子预览示例](/img/smart-download/settings-light.png)

## 选择资源

| 设置 | 含义 |
| --- | --- |
| 字幕要求 | 默认中文字幕。「中英字幕」接受中文或英文任一种；「任意」允许无字幕。标题含 Baha 的资源默认视为有中文字幕。 |
| Baha 优先 | 同集存在符合其他规则的 Baha 资源时优先选择它。可以取消仍在下载中的其他智能下载任务，下一轮再选择资源；已完成下载或手动创建的任务保留。 |
| 下载窗口 | 默认 48 小时，可设为 1–168 小时。资源发布时间必须在该集开始下载时间至窗口结束之间，包含边界。 |
| 下载超时 | 默认 120 分钟，留空或填 0 表示不限制。从 qBittorrent 的种子加入时间计时；重启 lani 不重置计时，复用下载器已有种子时沿用原时间。 |
| 下载时间 | 在原始放送时间上提前或延后，与季度的下载时间设置共用。 |

下载窗口约束资源的发布时间。即使两天后才开启智能下载，只要历史资源在对应剧集窗口内发布，仍可被选中。日程缺失、特殊篇、非整数集数、合集、编号无法唯一对应到当前季度单集的资源不会自动下载。编号同时参考剧集编号和 Bangumi 排序号，存在冲突时跳过。多个剧集同时发布时分别计算各自的窗口。

同集的合格资源按发布时间从早到晚选择。BD、BDRIP、DVD、DVDRIP，以及标题包含 v2 及以上版本、repack、proper、修正或修复标记的资源会被排除；还可配置下文的标题屏蔽规则。

预览按发布时间倒序展示，每次显示 30 行。lani 会预先读取足够的资源，以完整判断发布区间；尚未取完整的旧区间暂时置灰。蓝线和角标表示按当前草稿计算的开始下载时间。区间内没有资源时以灰色行显示「无匹配种子」。不符合规则的种子同样置灰，悬停或使用键盘聚焦时隐藏各列内容，居中显示排除原因；符合规则的种子悬停时以浅蓝色突出显示。

![暗色主题下悬停查看种子排除原因](/img/smart-download/excluded-dark.png)

## 超时与取消

后台每分钟重新检查一次，上一轮未完成时不会并发执行。开启智能下载的季度停止普通标题规则的自动入队，手动下载仍可使用。

超时先取消当前任务并完成清理，下一轮再选择资源。因超时或用户手动取消的智能下载资源会从该集之后的自动候选中排除；因 Baha 换源取消的资源仍可再次选择。下载器已完成的种子不会因超时被取消。取消清理失败时，可在任务详情中重试清理，清理完成前不会创建竞争任务。

任务详情将类型显示为「下载（智能下载）」，并展示超时或 Baha 换源的取消原因。用户主动取消时显示「用户手动取消」。关闭季度的智能下载只停止后续自动选源，已经创建的任务仍按创建时的参数执行。

## 标题屏蔽规则

在 lani 的 API 配置文件中添加 `smartDownload.rules.title.excludes`，重启服务后生效。任意一条正则匹配到种子标题，该资源就会被排除。

```yaml
smartDownload:
  rules:
    title:
      excludes:
        - '/Some-Raws/i'
        - '\[不需要的发布组\]'
```

支持普通 JavaScript 正则字符串，以及 `/表达式/标志` 写法；`i` 表示忽略大小写。为保证多次判断结果一致，不接受 `g`、`y` 标志。非法正则会使配置校验失败，请先修正再启动。

建议先在预览中核对资源标题、集数和发布时间，再保存季度配置。误匹配可通过屏蔽规则暂时避开，并在 [GitHub Issues](https://github.com/std4453/lani/issues) 提供资源标题及预期季度、集数。
