# 智能下载

智能下载可以为季度中的缺集自动选择资源，减少逐个配置标题匹配规则的工作。识别和选源可能出错，建议先核对已有资源的匹配结果，再开启自动下载。

## 开启前先确认

- **季度匹配使用可靠的识别模式。** 词法模式的识别准确率可能较低，不建议开启智能下载；弹窗出现词法模式警告时，先请管理员调整匹配配置。
- **种子列表能及时更新。** 在种子列表中确认近期资源持续进入，并能正确关联到本季度。Nyaa 资源还需要完成详情抓取；如果同步、解析或匹配长期停滞，先排查这些问题，否则智能下载可能错过合适的资源。
- **季度的剧集资料和放送时间基本正确。** 智能下载依赖集号与放送时间判断候选；资料缺失或明显有误时，先同步或修正季度资料。

智能下载与普通标题匹配规则的自动下载互斥。开启智能下载后，原有标题规则会保留，但不再用于自动下载；手动下载仍可使用。

## 检查候选后开启

在季度详情页的「下载配置」中点击「开启智能下载」，先查看设置弹窗中的种子列表。建议重点检查：

- 每集发布标记之后，是否很快出现了对应集数的有效候选；是否有其他季度、合集或特殊篇混入。
- 候选资源的字幕是否符合需要。「中英字幕」接受中文或英文任一种，「任意」允许无字幕；Baha 资源默认视为有中文字幕。
- 下载窗口是否覆盖常见资源的发布时间。设置过短可能排除字幕发布较晚的资源；窗口内有多个合格资源时，优先选择较早发布的资源。

![智能下载设置与种子预览示例](/img/smart-download/settings-light.png)

如果资源经常在剧集发布标记之前出现，或标记明显早于实际发布，可以调整下载时间的提前／延后偏移，再核对几集的候选变化。偏移应反映本季度实际的资源发布时间，避免只为某一条迟发资源调整整季设置。

灰色资源可查看无法下载的原因。如果明明有合适的资源却没有候选，先检查集号、字幕、放送时间和资源处理状态；发现误匹配时，可以用[规则集](#规则集)避开不合适的标题，并反馈问题。

确认候选符合预期后，开启智能下载并保存季度配置。开启后建议关注最初几次下载的实际内容，确认集数、字幕和文件正确；智能识别不能保证每次都准确。历史资源只要在对应剧集的下载窗口内发布，也可以被选中，无需在首播前就开启。

## 开启后的下载

开启 Baha 优先后，如果同集出现符合其他条件的 Baha 资源，仍在下载中的其他智能下载任务会被取消并重新选源；已完成下载和手动创建的任务保留。

下载超时从 qBittorrent 的种子加入时间计时，重启 lani 不重置；留空或填 0 表示不限制。失败、超时取消或手动取消的资源不会再次自动选择，因 Baha 换源取消的资源仍可再次选择。

关闭智能下载会停止后续自动选源，已创建的任务继续执行。若发现误下载，需要同时检查并处理已有任务。

## 规则集

在 lani 的 API 配置文件中添加 `smartDownload.rules.title.excludes`，重启服务后生效。任意一条正则匹配到种子标题，该资源就会被排除。

```yaml
smartDownload:
  rules:
    title:
      excludes:
        - "/Some-Raws/i"
        - '\[不需要的发布组\]'
```

支持普通 JavaScript 正则字符串，以及 `/表达式/标志` 写法；`i` 表示忽略大小写。为保证多次判断结果一致，不接受 `g`、`y` 标志。非法正则会使配置校验失败，请先修正再启动。

误匹配可通过规则集暂时避开，并在 [GitHub Issues](https://github.com/std4453/lani/issues) 提供资源标题及预期季度、集数。
