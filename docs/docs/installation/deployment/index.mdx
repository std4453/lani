# 部署方法

lani 的部署方式包括：

- [docker 一体机容器部署](./docker-all-in-one)（推荐）
  - 简简单单一个 docker 容器
  - 主流 NAS 均可使用
  - 只需一个配置文件
  - 打包 MinIO 服务
- [Kubernetes 集群部署](./k8s-deployment)：公开自托管指南尚未完成，目前没有可直接使用的安装步骤或公开部署模板。

这里介绍用户自托管方式。源码仓库的自动构建与维护者发布交接另见
[CI/CD 说明](https://github.com/std4453/lani/blob/next/.github/README.md)。
