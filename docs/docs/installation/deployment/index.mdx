# 部署方法

lani 的部署方式包括：

- [docker 一体机容器部署](./docker-all-in-one)（推荐）
  - 简简单单一个 docker 容器
  - 主流 NAS 均可使用
  - 只需一个配置文件
  - 打包 MinIO 服务
- [Kubernetes 集群部署](./k8s-deployment)

  - 高可定制性
  - 与已有的基础设施融合
  - 文件系统管理更自由

- [Kubernetes 迁移与持续部署](./migration-cd)
  - 多应用统一发布与 GitHub Actions 接入
  - 后端维护窗口、迁移阶段及人工接管
