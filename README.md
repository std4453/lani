# Lani

Lani 是自托管的动画媒体库管理工具，将季度元数据、资源选择、下载和媒体导入连接起来。你可以在网页中管理追番计划，通过 qBittorrent 下载资源，并将媒体及元数据同步到 Jellyfin。

## 开始使用

先阅读[用户手册](https://std4453.github.io/lani/docs/intro)，了解平台功能与[系统需求](docs/docs/installation/requirements.mdx)，再选择[部署方法](docs/docs/installation/deployment/index.mdx)。一体机容器适合集中运行服务，分体部署便于分别管理各组件。

部署后配置数据库、下载器、媒体目录和 Jellyfin，再在管理界面添加动画、设置下载源。资源识别可参考[种子季度匹配](docs/docs/torrent-matching.md)，元数据来源见 [bangumi-data](docs/docs/bangumi-data.md)。

参与项目请阅读[贡献指南](CONTRIBUTING.md)。
