# 智能下载判定

本包提供前后端共用的无副作用 TypeScript 判定函数。调用方传入完整季度目录、候选资源、配置和固定当前时间，得到候选资格及排除原因；前端另用发布区间生成预览角标和空行。

先在完整目录中按集数或排序号唯一定位，再应用每集独立窗口，避免缺集状态或窗口意外掩盖编号冲突。窗口只限制资源发布时间，因此配置修改、详情补齐及重启后均可重新计算历史候选。

调用方负责数据准备与状态处理：服务端等待详情、排除超时取消的资源、锁定剧集并创建任务；前端补齐发布区间后按 30 行逐步显示。展示中未补齐的区间暂时置灰，不据不完整数据提前判定 Baha 优先。

用户配置见[智能下载手册](../../docs/docs/usage/smart-download.md)，调度和取消约束见[下载任务设计](../../apps/api-server/src/download-job/DESIGN.md)。在本包运行 `node ../../common/scripts/install-run-rushx.js test --runInBand` 验证规则边界。
