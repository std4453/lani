# Nyaa 字幕语言标注语料

`corpus.json` 保存从 Nyaa 详情页响应中直接摘录的 `#torrent-description` 内容，以及有助于判断时的 `.torrent-file-list` 内容。页面标题用于样本识别，不作为字幕语言标注证据，因为被测抽取器只读取描述和文件列表。摘录保留页面原有的 Markdown、MediaInfo 轨道块或文件列表 HTML 结构；只剪去无关正文或文件项。没有下载 torrent、媒体或字幕文件。

搜索引擎摘要只用于发现可能的页面。每条 `html` 和 `evidence` 都以随后直接读取的 Nyaa 页面原文为准；搜索摘要没有被改装成 HTML，也没有作为标注依据。`capturedAt` 是直接采集页面的日期。

`languages` 是辅助 subagent 阅读原文、经开发任务复核的独立标注，不是被测解析器输出，也不是第三方人工认证；使用 BCP 47 标签。中文未注明字形时标为 `zh`，明确简体/繁体时标为 `zh-Hans` / `zh-Hant`；页面明确标注时保留 `es-419`、`es-ES`、`pt-BR` 等地区变体，未注明地区的 Spanish/Portuguese 使用 `es` / `pt`。北京语、广东语等语言/方言名称不用于推断中文书写体系，也不细分为独立代码。轨道标题（如 Signs、SDH、Forced）不增加语言；Romaji 不自动等同于日语字幕。音轨语言不自动计入字幕标签。

`status` 区分三种证据状态：

- `known`：保留的描述或文件列表直接给出字幕语言；`languages` 至少有一项。
- `none`：保留的描述直接且明确地声明没有字幕，例如 `No subtitles`、`no subs` 或 `Subtitles: None`。MediaInfo 未列出 Text 轨不足以证明无字幕，因为仍可能存在硬字幕或未列出的外挂字幕。
- `unknown`：保留的内容没有给出字幕语言，或只确认有字幕却没有说明其语言。没有描述、RAW 标记、标题中的“无字幕”都不能单独证明输入片段里的语言或状态。

样本为覆盖解析边界而有意挑选，不是随机样本，也不代表 Nyaa 内容分布或解析器总体准确率。样本覆盖多语言列表、简繁区分、真实 MediaInfo Text 轨、外挂文件列表、音轨语言干扰、描述缺失和否定语句。`holdout` 是在先前 holdout 已被开发者看过后重新挑出的五条挑战记录；请只用于最终评估，不据其标签调参。该固定子集仍不是统计学上独立的测试集。
